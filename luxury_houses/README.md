# luxury_houses — PREMIUM REAL ESTATE & INTERIOR SYSTEM

نظام عقارات فاخر لسيرفر **gta4gg / Liberty City**.
كل عقار له **بُعد (dimension) مستقل**، وجميع العقارات الآن تستخدم غرفة
**GTA V Online Eclipse Tower** حقيقية (ملفات DFF/TXD/COL أصلية) داخل بُعد العقار
فقط، مع رجوع إلى **نقطة الدخول نفسها** بالضبط. عالم المدينة الخارجي لم يتم تعديله.

## الداخل الجديد

- الأصول الحقيقية موجودة في `models/`:
  - `apt_mp_shell.dff` + `apt_mp_mod.txd` + `apt_mp_shell.col`
  - `apt_mp_int.dff` + `apt_mp_int.txd` + `apt_mp_int.col`
  - `apt_mp_props.dff` + `apt_mp_props.txd` + `apt_mp_props.col`
- `client.lua` يحمّلها في **custom object model IDs** عبر `engineRequestModel`
  ولا يستبدل أي موديل أصلي في GTA:SA.
- الغرفة تُنشأ داخل `interior 0` وبُعد `21000 + id` فقط. لا توجد أجسام
  للغرفة في البُعد 0، لذلك لا يتغير عالم LC الخارجي إطلاقاً.
- أرضية حماية غير مرئية تمنع السقوط عبر أي فجوة في المجسمات.
- `LH.gtav` في `config.lua` يحتوي على نقطة التمركز، الدوران، نقطة الدخول
  ومقاسات أرضية الأمان.

## للمطور — إضافة عقار جديد

افتح `config.lua` وأضف جدولاً واحداً إلى `LH.properties`:

```lua
{ key = "my_new_house", name = "My New House",
  ptype = "house", district = "Bohan",
  x = -1234.5, y = 678.9, z = 20.0, rot = 90,
  shell = 14526, price = 150000, rent = 0, capacity = 0,
  desc = "Short English description shown in the buy panel." },
```

لا تحتاج تعديل أي ملف آخر: الماركر، البلِب، البُعد، الداخل، نقطة الخروج،
الملكية، المفاتيح، المستودع، المرآب والواجهة الفاخرة كلها تُولَّد تلقائياً.

## الملفات

| الملف | الدور |
|---|---|
| `config.lua` | قائمة العقارات + كتالوج الأثاث + إعدادات الغرفة (shared) |
| `server.lua` | الملكية، المفاتيح، المستودع، المرآب، الأثاث، الأبعاد (server) |
| `client.lua` | تحميل الغرفة + واجهة DX سوداء/ذهبية + E للدخول (client) |
| `models/` | أصول GTA V الحقيقية للغرفة |
| `scripts/s_water.lua` | إنشاء بحر Liberty City على السيرفر (إصلاح الماء) |
| `water.dat` | 62 رباعية ماء LC |
| `measured.txt` | أبعاد قديمة محفوظة للتوافق فقط (لا تُنزَّل) |

## التحكم

| المفتاح | الوظيفة |
|---|---|
| **E** عند باب ذهبي | دخول العقار / عرض الشراء |
| **E** عند ماركر الخروج الذهبي | الخروج إلى نقطة الدخول نفسها |
| **M** داخل العقار | لوحة الإدارة (قفل، مستودع، أثاث، مرآب، بيع) |
| **الأسهم** أثناء وضع الأثاث | تحريك |
| **R** | تدوير ١٥° |
| **ENTER** | تثبيت |
| **BACKSPACE** | إلغاء |

## الأوامر

| الأمر | الوظيفة |
|---|---|
| `/myprops` | قائمة عقاراتك |
| `/givekey <player>` | إعطاء مفتاح (المالك فقط) |
| `/revokekey <player>` | سحب مفتاح |
| `/lhadmin give <amount>` | (أدمن) إيداع تجريبي في البنك |
| `/lhadmin reset <id>` | (أدمن) تحرير عقار |
| `/lhwater` | (أدمن) إعادة بناء بحر LC |

## الأبعاد

* `21000 + id` لكل عقار — لا تتعارض مع `9999` (غرفة إنشاء الشخصية) ولا `42000+` (ng-property).
* الغرفة تعمل في `interior 0` داخل هذا البُعد الخاص فقط.
* `ng-characters` لا يعتبر أبعاد العقارات "بُعد مؤقت".

## إصلاحات مرافقة

* `LC/interiors.map` تم إفراغه (أبواب معطوبة كانت تنقل اللاعب إلى العدم).
* أي حالة قديمة محفوظة داخل بُعد عقار تُنقل إلى باب العقار الخارجي عند التحميل.
* `onResourceStop` يُعيد أي لاعب داخل عقار إلى باب العقار قبل إيقاف المورد.
